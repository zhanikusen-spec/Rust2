# Rust: Остров — игра + сервер

Файлы:
- `index.html` — сама игра
- `server.js` — сервер (раздаёт игру и принимает игроков по WebSocket)
- `package.json` — зависимости (ws)
- `render.yaml` — настройки для Render

## Запуск у себя (проверка)
1. Установи Node.js 18+
2. В папке: `npm install`, затем `npm start`
3. Открой http://localhost:3000 — в меню «Играть» будет сервер «Crust · Render»

## Выкладка на Render
1. Создай репозиторий на GitHub и загрузи туда все файлы из этой папки.
2. На render.com: New → Web Service → выбери репозиторий.
   (или New → Blueprint — он сам возьмёт render.yaml)
3. Настройки, если не подхватились: Build Command `npm install`, Start Command `npm start`, Health Check `/health`.
4. После деплоя открой адрес вида `https://имя.onrender.com` — игра откроется там же,
   а сервер в списке «Играть» и в PvP-арене уже прописан: wss://crust-new.onrender.com.

Друзьям просто отправь эту ссылку.

## Заметки
- Бесплатный Render засыпает после ~15 минут без запросов; первое открытие тогда занимает до минуты.
  В списке серверов будет «проверка…», потом «онлайн».
- Если открываешь `index.html` с телефона/компьютера как файл, добавь адрес вручную в меню «Играть»:
  `wss://имя.onrender.com`.
- Проверка сервера: `https://имя.onrender.com/health`.
- Серверов 4: это 4 отдельные комнаты на одном Render-сервисе (`wss://host/?room=1` … `?room=4`). Игроки разных комнат друг друга не видят. Число комнат — переменная `ROOMS` (по умолчанию 4).
- Макс. игроков в комнате — переменная `MAX_PLAYERS` (по умолчанию 50).
- Онлайн по комнатам: `https://имя.onrender.com/rooms`.
- Сейчас онлайн работает как PvP-арена: игроки, стрельба, урон, убийства. Синхронизации
  острова (постройки, лут, животные) между игроками пока нет.

Протокол (JSON): клиент → `join {name}`, `s {состояние}`, `hit {id,d}`, `died {by}`;
сервер → `welcome`, `join`, `leave`, `s`, `dmg {d,from}`, `feed {k,v,kid,vid}`.
